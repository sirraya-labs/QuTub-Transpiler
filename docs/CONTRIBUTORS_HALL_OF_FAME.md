# Contributors Hall of Fame

The **QuTub Transpiler Contributors Hall of Fame** recognizes contributors who make meaningful, sustained, and impactful contributions to the project.

Recognition is based on the **quality and impact of contributions**, not simply the number of commits or pull requests.

---

## Contribution Credit System

Different types of contributions receive different credit values based on their impact.

| Contribution | Credits |
|---|---:|
| Major feature / subsystem | 10 |
| Significant bug fix | 5 |
| Meaningful optimization | 5 |
| Research / technical contribution | 5 |
| Test infrastructure / substantial test coverage | 4 |
| Documentation improvement | 3 |
| Community / mentoring contribution | 3 |
| Code review with meaningful technical impact | 2 |
| Meaningful issue investigation / bug report | 2 |
| Small code or documentation improvement | 1 |

Credits are assigned by maintainers based on the actual impact and significance of the contribution.

### Key Principles

- **Impact over quantity:** Meaningful contributions matter more than raw commit or PR counts.
- **Quality matters:** Contributions should be useful, well-maintained, and aligned with project goals.
- **Sustained involvement:** Higher recognition levels should generally reflect continued participation.
- **Multiple contribution types:** Contributions across different areas are equally valuable.
- **Maintainer discretion:** Credit values and recognition levels are guidelines, not automatic entitlements.
- **Fair recognition:** Contributors should be recognized based on their actual contribution and impact.
- **No duplicate credit:** The same work should not receive multiple credits unless it represents genuinely distinct contributions.

---

## Recognition Levels

### First Contribution

Recognizes a contributor who has made their **first accepted contribution** to QuTub Transpiler.

This may include a code change, documentation improvement, bug fix, test, research contribution, or another meaningful project contribution.

### Active Contributor

Requirements:

- At least **5 contribution credits**
- At least **2 meaningful contributions**

Recognizes contributors who have demonstrated continued involvement beyond their first contribution.

### Distinguished Contributor

Requirements:

- At least **15 contribution credits**
- Sustained meaningful involvement in the project

Recognizes contributors who have made significant contributions across one or more areas of the project.

### Hall of Fame

Requirements:

- At least **30 contribution credits**
- Substantial and sustained contribution to QuTub Transpiler

This level recognizes contributors whose work has had a significant and lasting impact on the project.

### Project Champion

Requirements:

- At least **50 contribution credits**

**or**

- Exceptional long-term contribution, leadership, mentorship, or major technical impact.

Project Champion is the highest recognition level and is intended for contributors who have demonstrated exceptional commitment and influence within the project.

> Recognition levels are guidelines rather than automatic entitlements. Maintainers may recognize exceptional contributions that do not fit perfectly within the credit system.

## Contribution Categories

Contributors may receive recognition in one or more of the following professional categories.

### Code

Development of features, improvements, refactoring, and other code contributions.

### Documentation

Improvements to documentation, guides, examples, references, and project explanations.

### Testing

Creation or improvement of tests, test infrastructure, test coverage, and quality assurance.

### Research

Technical research, experimentation, analysis, and contributions that help guide project development.

### Bug Fixing

Identification, diagnosis, and resolution of software defects.

### Code Review

Meaningful technical reviews that improve code quality, correctness, maintainability, or architecture.

### Performance

Optimizations that improve execution speed, memory usage, scalability, or overall system efficiency.

### Architecture

Contributions involving system design, architecture, infrastructure, or major structural improvements.

### Community and Mentoring

Helping other contributors, answering technical questions, mentoring, community support, and improving collaboration.

## Recognition Guidelines

Maintainers may periodically review contributions and update recognition levels.

Recognition should consider:

- Technical impact
- Quality of work
- Difficulty and scope
- Long-term usefulness
- Consistency of contribution
- Collaboration and community impact
- Contribution across multiple project areas

The credit system is intended to provide **transparency and consistency**, while allowing maintainers to use judgment when evaluating exceptional contributions.
