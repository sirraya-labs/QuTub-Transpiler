## Recognition Guidelines

The Hall of Fame is intended to recognize meaningful contributions to the QuTub Transpiler project.

Contributors can be added when they have made a contribution that has been accepted, reviewed, or recognized by the project maintainers.

Contributions may include:

- Code and feature development
- Bug fixes and testing
- Documentation and examples
- Useful issue reports
- Pull request reviews and feedback
- Design or technical discussions
- Community support

### How contributors are listed

- Contributors are listed according to the type of contribution they have made.
- A contributor may appear in more than one section if their contributions cover multiple areas.
- Core Maintainer status is determined by the project maintainers.
- Contributors should be added after their contribution has been reviewed or recognized by the maintainers.
- GitHub usernames should be used when possible to make the list easy to maintain.
- Existing entries should be kept up to date as the project grows.
