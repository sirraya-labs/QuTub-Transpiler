# Contributors

Thank you for contributing to **QuTub Transpiler**!

We welcome contributions of all kinds, including:

- Code and feature development
- Bug fixes
- Testing
- Documentation
- Performance improvements
- Code reviews
- Research and technical contributions
- Community support and mentoring

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear message.
5. Open a Pull Request.
6. Describe your contribution clearly.

Please make sure your contribution follows the project's coding and documentation standards.

## Contributors Hall of Fame

See the [Contributors Hall of Fame](docs/CONTRIBUTORS_HALL_OF_FAME.md) for contributors recognized for their meaningful contributions to QuTub Transpiler.

We appreciate everyone who helps improve the project!
